Alles, was du für Notizen brauchst

Block-Editor

Überschriften, Listen, To-dos, Toggles, Callouts, Code mit Highlighting, Tabellen, Spalten, Bilder und Dateien. Tippe / für alles.

Markdown beim Tippen

#, -, [], > und ``` werden sofort zu Blöcken. Fett, kursiv, Links und Hervorhebungen direkt per Kürzel.

Datenbanken

Tabelle, Kanban-Board, Kalender, Galerie und Liste. Auswahl, Datum, Relationen, Rollups und Formeln. Jeder Eintrag ist eine eigene Seite.

Verlinkt denken

Mit [[ auf andere Seiten verweisen. Backlinks zeigen, wer auf eine Seite zeigt.

Blitzschnell finden

⌘K bzw. Strg+K durchsucht Titel, Inhalte und Datenbank-Werte in Millisekunden und führt jeden Befehl aus.

Tastatur zuerst

Jede Kernaktion hat ein Kürzel; ⌘/ bzw. Strg+/ zeigt sie alle. Auf dem Mac mit ⌘, unter Windows mit Strg.

Deine Daten bleiben bei dir

Alles liegt in einer SQLite-Datei auf deinem Computer. Tägliche Backups, Versionsverlauf, Export als Markdown oder PDF.

Hell und dunkel

Ruhiges Design mit viel Weißraum, folgt dem System oder deiner Wahl.

Offline. Immer.

Flou macht keine einzige Netzwerkanfrage. Kein Login, kein Abo, kein Tracking.

Installation

Windows

  1. Flou-Setup.exe herunterladen und doppelklicken.
  2. Zeigt Windows „Der Computer wurde durch Windows geschützt“: auf „Weitere Informationen“ und dann „Trotzdem ausführen“ klicken.
  3. Den Installer durchklicken. Flou steht danach im Startmenü.

Windows 10 oder 11, 64 Bit. Keine Administratorrechte nötig.

Mac, am einfachsten

Mac per Terminal

Lädt die aktuelle Version, installiert sie nach Programme und startet sie, ohne Sicherheitswarnung:

curl -fsSL https://github.com/__REPO__/releases/latest/download/install.sh | bash

Terminal öffnest du mit ⌘ Leertaste → „Terminal“.

Mac per Download

  1. Flou.dmg herunterladen und öffnen.
  2. Flou in den Ordner Programme ziehen.
  3. Beim ersten Öffnen meldet macOS, dass Apple die App nicht prüfen konnte. Dann: Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“.

Warum die Sicherheitsmeldungen? Flou ist kostenlos und deshalb nicht kostenpflichtig bei Apple bzw. Microsoft signiert. Der Quellcode ist offen auf GitHub einsehbar.

Häufige Fragen

Wo liegen meine Daten?

Mac: ~/Library/Application Support/app.flou.desktop/, Windows: %APPDATA%\app.flou.desktop. Dort liegen Datenbank, Bilder und Backups. Nichts verlässt deinen Computer.

Wie aktualisiere ich Flou?

Einfach die neue Version wie oben installieren. Deine Daten bleiben erhalten.

Läuft Flou auf Intel-Macs?

Aktuell nur auf Macs mit Apple Silicon (M1 und neuer). Unter Windows auf allen 64-Bit-PCs mit Windows 10 oder 11.

Wie deinstalliere ich Flou?

Mac: Flou aus Programme in den Papierkorb legen. Windows: Einstellungen → Apps → Flou → Deinstallieren. Wer auch die Daten löschen will, entfernt zusätzlich den Datenordner.
